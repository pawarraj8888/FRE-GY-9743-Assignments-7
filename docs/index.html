The curves

Value date 2026-01-02. The library's piecewise constant curve holds each interval at the value of its right-hand node; the new curve passes through the points, has a continuous derivative, and is monotone and convex on every node interval. The one-node funding curve (5 bp over SOFR) is a constant under both.

The method in one paragraph

The inputs are IFR values at the nodes, so the free quantities are the node slopes. An interior node gets the weighted harmonic mean of the two neighbouring chord slopes (zero at a local extremum or next to a flat interval, never more than twice the smaller chord); the two end nodes get the slope of the parabola through the three outermost points, limited the same way. On each interval the derivative is piecewise linear through the left slope, a knot slope and the right slope, and the curve is two quadratics joined with a continuous derivative. When the end slopes straddle the chord the knot is placed where one piece becomes a straight line, so the derivative runs monotonically from one end slope to the other: the piece is convex (or concave for concave data) and, since every slope has the chord's sign, monotone. When both slopes sit on the same side of the chord no convex C1 piece exists; the knot goes to the midpoint and the slope cap keeps the piece monotone. This is Hagan and West's recipe (local node estimates, piecewise quadratics, a flat segment inserted to protect monotonicity) moved from interval averages to point values.

interior slope: di = (w1 + w2) / (w1/si + w2/si+1),   w1 = 2hi+1 + hi, w2 = hi+1 + 2hi,   |di| ≤ 2 min(|si|, |si+1|);   knot slope m = 2si − (αdi−1 + βdi)/hi.

On rising data the piecewise constant step sits above the point curve everywhere, so the new curve gives smaller floating legs and slightly larger discount factors: both receivers of fixed gain. The swap moves most through its last period, where the step jumps to the 5Y value of 4.7% right after the 3Y node while the new curve is still near 3.6%. The basis swap receives the SOFR–FF gap, which the step takes from the right-hand node of each interval; the new curves pass through the point gaps, so the gap, and the PV, shrink.
